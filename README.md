# CareerCraft AI

CareerCraft AI is an AI-powered career assistant providing career prediction, mock interviews, course and job recommendations, and salary prediction.

## Features
- **Career Prediction:** Suggests careers based on skills.
- **Mock Interviews:** Practice interviews with AI.
- **Recommendations:** Get personalized course and job recommendations.
- **Salary Prediction:** Predict salary ranges.

See `server` and `client` directories for backend and frontend setups.
